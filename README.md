# Education Platform Website

An education platform website built based on a Figma design.

## Design

Figma: [Education Platform Website](https://www.figma.com/design/Vyto82ebt8E0GoqBtpzGfS/02.-Education-Platform-Website--Easy-?node-id=0-1&p=f&m=dev)

## Technologies

- HTML5
- CSS3

## Features

- Clean and modern user interface
- Education platform website layout
- Organized CSS styles
- Responsive layout

## Project Structure

```text
EducationPlatform/

│   │   └── styles.css
│   ├── fonts/

```

## Getting Started

1. Clone the repository.

```bash
git clone https://github.com/tuongdp/education-platform-website.git
```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` in your browser or use the Live Server extension.

## Purpose

This project was created to practice converting a Figma design into a website using HTML and CSS.
